# Senarai - Belajar Skill Abad 21

![Senarai Logo](https://img.shields.io/badge/Senarai-Skill%20Abad%2021-green?style=for-the-badge)

**"فَرْضُ عَيْنٍ untuk setiap manusia di abad ke-21"**

Direktori aktivitas pembelajaran yang dikurasi komunitas untuk anak-anak Indonesia dari PAUD hingga Profesional.

## 🌟 Tentang Senarai

Senarai adalah platform pembelajaran yang dirancang khusus untuk menghadirkan kurikulum abad 21 bagi anak-anak Indonesia. Kami percaya bahwa skill digital dan pembelajaran sepanjang hayat adalah kewajiban individual (*fardhu 'ain*) yang harus dimiliki setiap orang di era modern.

### 🎯 Filosofi

> "فَرْضُ عَيْنٍ untuk setiap manusia di abad ke-21"

Skill abad 21 bukanlah pilihan, melainkan kebutuhan fundamental yang harus dimiliki setiap individu untuk berkembang di masa depan.

## 📚 Fitur Utama

- **98+ Aktivitas Pembelajaran** - Kurikulum lengkap dari PAUD hingga Profesional
- **12 Kategori Usia** - Konten yang disesuaikan dengan tahap perkembangan
- **Filter & Pencarian** - Temukan aktivitas yang sesuai dengan mudah
- **Mobile Responsive** - Akses dari perangkat apa pun
- **Community-Driven** - Dikurasi oleh komunitas pendidik Indonesia

## 🎨 Kategori Usia

- **PAUD** - Preschool/Early Childhood
- **PAUD ke atas** - Preschool+
- **SD** - Elementary
- **SD ke atas** - Elementary+
- **SMP** - Middle School
- **SMP ke atas** - Middle School+
- **SMA** - High School
- **SMA ke atas** - High School+
- **Kuliah** - University
- **Profesional** - Professional
- **Semua Usia** - All Ages
- **For Parents** - Panduan untuk Orangtua

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Tailwind CSS via CDN
- **Architecture**: Static Site (SPA feel)
- **Data**: Embedded JSON
- **Deployment**: Netlify

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/ainunnajib/senar-ai.git
cd senar-ai

# Serve locally (any HTTP server)
python -m http.server 8000
# atau
npx serve .

# Open http://localhost:8000
```
